VR Experience

An interactive VR experience built in Unity with SteamVR for the Valve Index, featuring physics-driven minigames set in a stylised low-poly environment.

The project includes a tropical hub world that connects to distinct minigames — a can-smash target gallery and a balloon shooting range. Each minigame implements its own scoring and lives system displayed through in-world 3D UI elements.

VR interactions include physics-based grabbing and throwing, two-handed weapon handling for the rifle in the shooting range, and interactive buttons and levers. Locomotion combines smooth joystick turning with teleportation movement.

The environment features a consistent low-poly art style with flat shading, and the project implements in-world instructional text, laser-pointer interactions for distant UI, and a full game loop with score tracking across all minigames.
